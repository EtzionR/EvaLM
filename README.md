# EvaLM
Evaluation of Language models outputs using SA and Cosine similarity

created for my Lecture: **Language Models for Social Science**

This repo contain two .ipynb files:
- [**wiki_2_data.ipynb**](https://colab.research.google.com/github/EtzionR/evalm/blob/main/wiki_2_data.ipynb): For loading wikipage, rewite it and save the results into file.
- [**Text_Evaluation.ipynb**](https://colab.research.google.com/github/EtzionR/evalm/blob/main/Text_Evaluation.ipynb): For analyze the output data created by [wiki_2_data.ipynb](https://colab.research.google.com/github/EtzionR/evalm/blob/main/wiki_2_data.ipynb).
